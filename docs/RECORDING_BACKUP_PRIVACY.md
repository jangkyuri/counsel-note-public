# Connect Log Recording Backup 개인정보 안내

이 안내는 개인 PC의 **Google Drive 녹음 백업 기능**에만 적용됩니다.
상담 정리, ADMIN 저장 등 앱의 다른 기능 전체를 설명하는 문서는 아닙니다.

## 처리하는 정보와 목적

- 로컬에서 읽는 정보: 사용자가 선택한 녹음 및 지정한 녹음 수신 폴더의
  음성 파일, 파일 이름, 크기, 수정 시각, 내용의 해시입니다.
- Google Drive에서 읽는 정보: 지정한 백업 폴더 안의 파일 목록, 이름,
  크기와 해시 등 중복 확인 및 저장 확인에 필요한 정보입니다.
- Google Drive로 보내는 정보: 아직 백업되지 않은 녹음 파일과 파일 이름
  등 업로드에 필요한 정보입니다.
- PC에 보관하는 정보: 연결 인증 정보, 백업 설정, 처리 상태와 오류 구분,
  백업 결과 확인에 필요한 기록입니다.

이 정보는 녹음 보존, 내용 기준 중복 방지 및 업로드 결과 확인을 위해
사용합니다. 이 백업 기능은 녹음 내용을 분석하거나 광고·판매·AI 모델
학습 목적으로 사용하지 않습니다.

## 전송 대상과 공개 범위

녹음은 사용자가 연결한 Google 계정의 지정된 Drive 폴더로 전송합니다.
이 기능을 위한 별도의 중계 서버에 녹음을 저장하지 않습니다. 저장된 파일의
열람 범위는 해당 폴더와 파일의 Google Drive 공유 설정에 따릅니다.
폴더가 링크 공유 상태라면 링크를 가진 사람이 접근할 수 있으므로,
백업을 한다는 사실이 파일을 비공개로 전환한다는 의미는 아닙니다.

이 안내 페이지에는 실제 녹음, 학생정보, 전사본, 인증 정보 및 비공개 운영
기록을 게시하지 않습니다. Google 서비스 자체의 정보 처리는 Google의
개인정보처리방침과 설정에 따릅니다.

## 권한과 인증 정보

현재 rclone Drive 연결은 파일 조회·생성·수정·삭제가 가능한 넓은 Drive
권한을 요청합니다. 이 백업 기능은 지정된 폴더의 목록 조회, 중복 확인,
새 녹음 업로드와 저장 확인에만 사용하며, 파일 삭제나 공유 변경을 수행하지
않습니다. 인증 정보는 사용자 PC의 rclone 설정에 보관하며 GitHub에
게시하지 않습니다. 이 설정 파일을 다른 사람에게 전달하지 마세요.

## 보관과 삭제

백업 기능은 로컬 원본과 기존 Drive 파일을 자동으로 삭제하지 않습니다.
전송 중 사용하는 임시 사본은 정상적으로 백업 시도를 마치면 정리합니다.
PC 강제 종료 등으로 임시 사본이 남을 수 있습니다. 백업 기록과 인증 설정은
사용자가 PC에서 제거할 때까지 남을 수 있습니다.
Drive에 저장된 녹음은 사용자가 Drive에서 직접 관리·삭제해야 합니다.

Google 계정에서 앱의 접근 권한을 해제하면 이후 백업을 위해 다시 승인이
필요합니다. 권한 해제나 PC 설정 제거는 기존 Drive 파일을 삭제하지 않습니다.
